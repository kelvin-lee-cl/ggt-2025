Capstone 3

Create your 60 sec AI avatar

Plan and produce a short clip featuring an AI-generated avatar that introduces you or shares one idea you care about.

Objective

Demonstrate how you script, generate, and edit a ~60 second avatar-led video, including credits for tools and any voice or imagery sources.

Project outline
  • Write a tight script (about one minute spoken).
  • Create or choose an avatar look; generate visuals and lip-sync or narration as required.
  • Edit into a single MP4 (or platform link if hosted).
  • Submit a HeyGen, YouTube, or Google Drive link plus a short “making of” note on the submission page.
